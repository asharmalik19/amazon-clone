The card is a tile in a grid answering "is this the thing I want?"; a cart line is a row answering "is this what I am buying?" -- different shape, different information, and it carries a quantity and two controls the card knows nothing about. Bending the card to be both is what would make both worse, so the card stays the only way a product is *browsed* and this is the only way one is *listed*. The rating is left off for the same reason: a shopper who has put the thing in their cart has finished evaluating it. Both controls are real forms posting to real URLs, with `hx-post` layered on -- the same shape as Add to Cart. With script, HTMX replaces the cart contents region in place. Without it, the browser posts the form and follows the `303` back to `/cart` with the change applied: a page navigation, not a dead control. Quantity is a select plus a visible **Update** button rather than an auto-submitting select, because auto-submit is a JavaScript behaviour: without it a shopper would be left holding a changed select and no way to commit it.
