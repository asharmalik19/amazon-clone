**Judgement calls worth flagging**

- **The styled 404 is Phase 13's bullet, landed early.** "Unknown product" is a state this phase has to handle and a JSON body is not a screen. The rest of the error surface stays with Phase 13.
- **`?image=` is parsed as text, not declared `int`.** As an `int` param, `?image=banana` is a 422 framework page; a hand-edited URL is a bad URL, not a missing product, so out-of-range and unreadable values both fall back to the first image.
- **No invented stock, delivery date or seller** — the catalog doesn't know them. A test asserts those strings stay absent.
- Quantity and Add to Cart are Phase 8, so the buy box says so where they'll go.

Two bugs came out of actually looking at the page rather than the tests: the image stage needed a fixed height (a square image pushed the title and price below the fold on a phone), and `max-h-full` does not constrain an image that has its own intrinsic size inside a centred grid area — it rendered at 600px and spilled out, fixed by positioning it against a parent with a definite height.
